# App icon

Generated with built-in ImageGen, 2026-09-08. Original PNG retained; packaging produces native ICNS sizes with sips/iconutil.

Prompt: Production-ready macOS app icon for a personal account switcher, no text or OpenAI logo. Deep evergreen rounded-square satin tile, ivory and mint opposing rounded arrows forming a compact switch loop, integrated quota bar, restrained bevel, transparent outside tile, legible at small sizes.

Quota presentation independently implemented in SwiftUI, inspired by the window-based usage meters and reset countdowns in https://github.com/steipete/CodexBar . No source code or artwork copied from that project.
